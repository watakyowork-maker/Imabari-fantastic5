 # 今治の観光地を紹介するアプリ

私たちは5人1チームで、今治の観光地を紹介するWebアプリを開発します。  
このREADMEは「開発ルール」をまとめたものです。  

---

## 🚫 絶対にやってはいけないこと
- **mainブランチを直接編集しない**  
  → mainは「完成した状態」を保つための場所です。  
- **git push origin main をしない**  
  → mainを壊す原因になります。必ずブランチを切って作業してください。  
- **他の人のブランチを勝手に編集しない**  
  → 自分の作業は自分のブランチで行いましょう。  
- **コミットメッセージを適当にしない**  
  → 「変更内容がわかる短い説明」を必ず書きましょう。  
  例：`今治城の画像を追加`  

---

## ✅ ブランチの作り方と名前のルール
- 新しい作業をするときは **必ずブランチを切る**  
- ブランチ名は次の形式に統一する 
    feature/自分の名前-作業内容 
- 例：
- 画像を追加する場合  
  ```
  feature/kiyominn-add-image
  ```
- ナビゲーションバーを修正する場合  
  ```
  feature/watakyo-fix-navbar
 
  ```

## 🔒 マージのルール
- **mainブランチへのマージは、リポジトリオーナー（わたきょさん）が行います。**  
- 他のメンバーは必ず **Pull Requestを作成** し、レビューを受けてください。  
- PRが承認されたら、わたきょさんが「Merge pull request」を実行します。  
- 競合が起きた場合は、必ずチームで相談してから解決します。
